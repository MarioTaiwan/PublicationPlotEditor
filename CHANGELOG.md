# v0.7

- Independent CorelDRAW EMF correction factors for X tick labels, Y tick labels, X axis label, and Y axis label.
- Calibration dialog accepts measured CorelDRAW point sizes and calculates corrected factors; also supports manual multipliers.
- Master templates and figure recipes persist all four correction factors.
- Master/figure save and export capture the X/Y font sizes currently entered in the GUI.
- Backward-compatible migration from v0.6/0.6.1 two-factor EMF calibration.
- PDF/FIG export stays uncorrected; only EMF receives calibration.
